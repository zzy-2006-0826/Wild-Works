## 搭建过程小结

这次装 Ubuntu 虚拟机，基本是 Agent 一步步带着我做的。它先告诉我 0xC0000005 那个报错不是 Linux 的问题，而是 Windows 的 Hyper-V 把 CPU 的虚拟化功能占用了；后来又看出虚拟机名字里有个「位」字，vmx 文件才一直建不出来。方法给得挺具体，但真正动手的都是我自己：关 Hyper-V、关内存完整性、建 D:\VM 文件夹、右键用管理员身份打开 VMware、装系统时分区，这些都是我看完说明、觉得没问题了才点下去的，毕竟是改系统设置，心里还是有点怕。

中间也踩了坑。第一次一开机虚拟机就崩了，把和 Hyper-V 有关的几个功能和内存完整性都关掉、重启之后才恢复正常；重新新建虚拟机又卡在「系统找不到指定的文件」，名字改成 ubuntu64、位置换到纯英文的目录就顺利过了。

以前一遇到报错就想着重装，现在知道先看提示和日志，比如 systeminfo 就能看出虚拟化有没有被别人占用。Agent 讲得再细，也得自己核对一遍再执行，这样才踏实。
