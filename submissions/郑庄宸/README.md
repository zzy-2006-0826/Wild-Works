## 心得体会

这次练习中，Agent 帮我整理了分步骤的命令表，并解释每条命令的作用。我逐条输入命令，再用 pwd、ls 和 cat 核对结果，练习了目录切换、创建文件、复制、移动、重命名和删除。最需要留意的是当前目录和文件名，文件改名后，后续查看也要使用新名字。环境检查发现现有系统是 Ubuntu 24.04，与作业要求的 22.04 有差异。考虑到正在比赛，我决定赛后再搭建 22.04 环境。这个过程让我认识到，使用 Agent 时应检查实际输出，如实记录环境和操作结果，并由自己确认删除等操作。
