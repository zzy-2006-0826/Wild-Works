## 心得体会

本次作业在 Agent 的协助下，我在 Windows 11 宿主机上用 VirtualBox 搭建了 Ubuntu 22.04 虚拟机，并完成了一组基础命令练习。Agent 帮我规划了从安装虚拟机、挂载镜像到系统配置的完整步骤，逐条解释了 pwd、ls、cd、mkdir、touch、cp、mv、rm、cat、head、tail 等命令的用途和预期结果，让我不必一边查文档一边摸索；而每一步的实际操作和结果确认，仍由我自己在终端中完成。

搭建过程中遇到几个问题：一是按 F2/F10/Del 无法进入 BIOS，后来通过 Agent 查询确认这台机器的虚拟化功能已经开启，无需手动设置；二是从官网下载 VirtualBox 安装包时连接超时，改用清华镜像源后顺利下载；三是虚拟机初始只分了 2GB 内存，导致图形终端反复崩溃，加到 4GB 后解决；四是在主目录创建练习文件时提示权限不足，于是改用 /tmp/practice 作为专用练习目录，命令练习得以顺利完成。这让我体会到，遇到网络或环境问题时，先判断根因，再换用可信镜像或调整配置，往往比反复重试更有效。

通过练习，我对目录定位、文件操作和文本查看三类命令更加熟练，尤其是 -i 参数的确认提示和 less 分页查看。同时我也感受到，Agent 能把模糊的问题拆解成可执行的步骤，但关键操作仍需自己动手验证，这种"人机配合"的方式效率很高，也让我对 Linux 命令有了更直观的理解。
