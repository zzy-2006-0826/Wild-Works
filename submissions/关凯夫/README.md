## 心得（约 200 字）

这次搭环境主要是 Agent 在跑：它先写脚本启用 WSL、导入发行版、装 Docker，再用 `ubuntu:22.04` 起容器，我在旁边看着并确认关键步骤。

需要我自己拍板的有几处：先用虚拟机还是 Docker、Docker Desktop 换成容器这个方案变更、重启电脑，以及最后要不要装图形桌面。

遇到的问题里最典型的是本机一开始既没有 Docker 也没有 VMware，让豆包直接装 Ubuntu 时失败了；我改成自己先下载安装 Docker，装了很久才通，中间还遇到容器里 apt 报证书不受信任、`less` 没预装。对初学者来讲，真有点懵。

收获是摸清了装软件前先确认前置条件的顺序，也记住了 `cp -i`、`mv -i`、`rm -i` 这类交互确认的用法。
