## 心得

这次在 Windows 11 上通过 WSL2 安装 Ubuntu 22.04。下载缓慢时，Codex 帮我分析可能是网络问题，我切换网络后重新执行并完成安装。
它也帮助我理解了常用命令的作用：`pwd` 用于确认当前路径，`ls -la` 能显示权限和隐藏条目，`cd` 配合 `~` 和 `..` 完成目录切换；`mkdir -p` 可以创建多层目录，`touch` 用于新建文件或更新时间。
文件操作中，`cp` 负责复制，`mv` 兼具移动和重命名功能，`rm` 用于删除；命令加上 `-i` 后，会在覆盖或删除前再次询问，从而减少误操作。
查看文本时，`cat` 显示全部内容，`head -n` 和 `tail -n` 分别查看开头和结尾。
最后由我亲手输入命令、核对输出并截图，我认识到理解命令用途比机械记忆写法更重要。
