# 虚拟机搭建实践

| 项目 | 内容 |
|---|---|
| 姓名 | 王梓宁 |
| 宿主机系统 | Windows 11 家庭中文版 25H2 |
| 虚拟化方式 | VirtualBox 7.2.22 虚拟机 |
| Ubuntu 版本 | Ubuntu 26.04.1 LTS Desktop（GNOME / Wayland） |
| Agent 工具 | DeepSeek Harness（deepseek-flash） |

## 心得

我用 DeepSeek Harness 从零搭了一台 Ubuntu 26.04.1 虚拟机。宿主机是 Windows 11 家庭版，没有 Hyper-V 管理器，所以选了 VirtualBox 7.2.22并采取国内镜像安装。Agent 负责探测硬件、下载校验 ISO、静默安装、创建虚拟机（4 核 / 6 GB / 64 GB）并写好初始化脚本；而 UAC 提权、分区和账号设置、强制断电、建快照，都由我确认后才执行。

在这个过程中，我也遇到了不少挑战，但也产生了一些对于技术的思考。由于没有计算机相关专业知识，操作过程中几乎每一步都要截图问Harness。但DeepSeek总是能给我详细的解答、解答的同时不断通过代码调整程序，像是一位经验丰富的电脑专家。我发现，只要我能够清晰的表达自己的需求以及遇到的困难，几乎都能得到回应与解决。虽然AI不能一次性做到最好，但我的反馈会给予它下一步的方向。比如在复制粘贴DeepSeek给我的代码时，我发现ctrl+v不能再虚拟机中使用，我于是求助，一开始Harness认为由于增强功能没有安装成功，于是给了我一段测试代码，让我输入后把虚拟机的输出截图给它。然后发现了问题，原来快捷键应该变成ctrl+shift+v。

收获是会使用Harness借助VBoxManage和日志定位问题，但抹盘、断电这类不可逆操作在执行前必须与AI确认。
