## 三、心得体会
我借助chatgpt和大肥鱼完成配置，通过截图询问成功弄懂了乌班图的基本操作与开荒教程，codex和dsh都很好用，关键是去做，去问，去实践，发现问题再用ai解决问题。遇到的问题是不懂github和git，时间紧任务重，只能保证完成，没法保证质量。“先知道自己在哪”。用 pwd 确认位置，用 ls 查看周边，配合 Tab 键补全，是避免瞎操作的前提。拿到一个仓库，最忌讳上来就乱改。标准的动作是用 git clone 拉取代码后，第一时间用 less 去阅读 README.md（项目说明）和 CONTRIBUTING.md（协作规范）。先读入口和约定，再决定改什么。Linux 的终端没有回收站，所以 rm 是一把双刃剑。我必须养成用 -i 参数或者先确认路径再删除的习惯。在查看文件时，我学会了用 less 替代 cat 去看长文件，并牢记了随时按 q 退出阅读模式。
