1. 在 VMware Workstation 中创建 Ubuntu 虚拟机，NAT 网络，分配 2 核 / 6 GB 内存。

3. 用 Agent 排查并修复了两个环境问题：主机与虚拟机之间剪贴板不通、系统版本与作业要求不一致。
