# 第二课作业：Ubuntu 环境搭建与 Agent 实践

## 基本信息

- 姓名：孟祯祺
- 宿主机系统：Windows 11 家庭版（AMD64）
- 环境方式：WSL2（Windows 子系统，虚拟机平台）
- Ubuntu 版本：Ubuntu 22.04.5 LTS（VERSION_ID=22.04）
- 使用的 Agent 工具：豆包（AI 助手），协助规划环境方案、诊断报错、下载并校验安装包、整理命令练习步骤

## 心得体会

我第一次接触 Ubuntu 和命令行，起初连终端、目录、路径都分不清。在 Agent 帮助下，我先理清要交什么，再一步步把环境搭起来。遇到两个问题：一是 PowerShell 不是管理员身份，报"请求的操作需要提升"，Agent 判断是权限不够，要以管理员身份运行；二是在线安装卡在 12.5%，Agent 判断为下载停滞，改为离线下载 WSL 包和 Ubuntu 镜像，校验完整后导入。

练习时我在专用目录里跑了三组命令：`pwd`、`ls`、`cd` 定位目录；`mkdir`、`touch`、`cp`、`mv`、`rm` 增删和复制移动；`cat`、`head`、`tail` 查看内容。方案和命令解释由 Agent 给建议，是否执行、最终核对由我自己完成，删除只针对自己建的练习文件。

这次让我对终端操作有了直观认识，也明白 Agent 适合给方案、排错，但关键判断和最终提交还得自己负责。
