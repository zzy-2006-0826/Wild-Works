# 心得体会

今天使用 Agent 完成课程练习，让我感受到清晰沟通的重要性。提出任务时，说明目标、已有环境、交付内容和操作边界，Agent 才能给出更准确、可执行的帮助；遇到 Ubuntu 命令报错，也可以把现象和提示提供给它，一起缩小排查范围。处理 Git 教程时，我尝试让主 Agent 规划任务、子 Agent 分别修改和审查，体会到把工作拆分并明确职责能提高协作效率。Agent 可以协助查资料、整理文档和检查差异，但输出仍需要我核对：确认引用和路径正确、修改符合要求，再由自己决定是否提交。今后我会把 Agent 当作能讨论、能协作的工具，持续补充必要背景，并对关键结果亲自验证；这样既能节省重复劳动，也能对最终成果负责。
