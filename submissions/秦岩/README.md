## 心得体会
在此之前的课程作业上我已经安装了Ubuntu22.04，所以本次实验就直接使用。Agent帮我列了学习计划并解释了 cp -i、mv -i、rm -i 的确认提示在什么条件下出现。练习中遇到两个问题：一是 cd Documents 报"没有那个文件或目录"，Agent指出中文系统的家目录默认是中文名，改用cd文档后正常；二是整段粘贴命令时，确认提示会把粘贴进来的下一行当成答案，导致 rm -i 实际没有删除文件，改成一条一条执行、提示后手动输入 y/n 后结果就对了。通过这次实验明白了 ls -la 里的"总计"是磁盘块数而不是文件个数，在家目录和根目录下数值差别很大，在操作前先用 pwd 确认所在目录，报错时先看提示符路径，很多问题就能自己定位。
