## 心得（约 200 字）

这次练习里，Agent 帮我把每一步的命令和结果对上号：先确认系统版本，再整理目录定位、文件新建和文本查看的命令，执行前解释每条命令做什么。新建、删除这类会改动的操作，它先列出命令、我确认后才跑；查看类命令由我自己敲、自己看输出。

中途卡在一个小错上：我顺手敲了 `cd home`，终端报"没有那个文件或目录"。Agent 指出这是相对路径的问题——当时我在 `~/study-notes` 下，那里并没有 home 目录，应写成 `cd /home`，回家目录用 `cd ~`。改成 `cd /home/xiaoguo` 后，提示符从 `~/study-notes` 变成 `~`，才算确认自己进对了。

收获是分清了绝对路径和相对路径、记住了 `~` 的含义，也养成了先看解释、再自己敲一遍的习惯。
