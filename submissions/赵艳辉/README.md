agent首先帮我完成了ubuntu环境的搭建，在搭建的过程中遇到字体更改以及无法更改输入法的问题，在agent的指导下，我把系统字体改为中文并且下载了中文输入法。在搭建环境的最开始，agent要我清理.lck锁的残留，目录里有三个文件夹，agent让我直接删除，但显示文件正在运行无法删除，然后我确认任务管理器没有 vmware-vmx.exe，再等挂起释放，然后目录里 .lck 消失，.vmss 出现，说明停在挂起态而非损坏。对agent工具使用的收获是，很多时候完全按照agent给出的指令去执行无法解决问题，还需要人工补充运行中出现的问题，并交给agent修改方案，才能妥善地解决问题。
