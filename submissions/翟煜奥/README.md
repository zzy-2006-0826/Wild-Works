本次作业在 Agent 帮助下完成 Ubuntu 22.04 环境搭建和基础命令练习。Agent 协助规划虚拟机配置与安装步骤，解释向导选项含义，并在命令报错时帮助定位；新建虚拟机、确认安装类型、设置账号密码等关键操作由本人确认后执行。

练习中主要问题是命令路径和参数输入不规范：查看版本文件时漏写开头斜杠，tail 命令把 `-n` 误写成 `=n`，示例文本换行符一度未生效。我通过 `ls -la`、`cat` 核对文件结果，并用 `printf` 重写文件后解决。

刚开始观看视频时，我对命令是一头雾水的，但是通过本次实践，我熟悉了目录定位、文件操作和文本查看等常用命令，也体会到 Agent 适合规划步骤、解释概念和辅助排错，所以在学习新知识时，不能只向内输入，也要尝试向外输出，这样才能真正理解掌握所学知识。
