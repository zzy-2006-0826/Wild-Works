在Ubuntu环境的搭建中，agent帮助我规划虚拟机配置，并带我了解虚拟机与宿主机之间的关系；此外，agent还帮我指出一些命令的运用错误，纠正并示例正确的运用方法。然而一些具体的网站，安装包等资料是由自己搜索整合并运用的。对于agent的使用，我明白agent不是一个全能的工具。它可以为问题的解决指出明确的方向（ex:搭建ubuntu的顺序），但不能真正的指出每一步应该怎么做或者是怎么做更省事（ex:推荐前往官方网站下载，但相对与其它网络资源速度慢），甚至于会做出一些错误的动作，因而在agent使用过程中，我们也需要有自我思考。
