第二次课堂作业

李博韬

Windows11

&#x20;环境方式：Oracle VirtualBox 虚拟机

Ubuntu版本：Ubuntu 22.04.5 LTS

Agent工具：豆包，deepseek



本次在Agent辅助下完成Ubuntu环境搭建与基础命令练习。Agent帮我梳理了操作步骤，在我遇到报错时快速定位问题，比如虚拟机全屏无法退出、命令格式错误、命令不存在等问题，都给出了直接可用的解决命令。而自己确认的部分有他们给的建议是否可信，以及每一步都是我具体操作与进行的（比如在虚拟机设定时豆包一直强调右侧Ctrl，可我键盘没有，于是最后我自己解决的）。

练习过程中遇到的主要问题有：误触进入虚拟机全屏找不到退出方式；输入命令时遗漏空格、字母拼写错误导致执行失败；lsb\_release命令不存在无法查看版本。最终通过Agent指导，改用cat /etc/os-release查看版本，修正命令格式后全部执行成功。而全屏切换问题Agent每一点用，他们方法行不通，我直接关机重启解决了。

这次作业让我掌握了Linux基础文件操作命令，理解了命令行的语法规则，也体会到用Agent辅助排错能大幅提升效率，为后续无人系统相关的Linux学习打下了基础。
