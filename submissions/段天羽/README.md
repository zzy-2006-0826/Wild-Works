# 第二课作业：段天羽

- 宿主机系统：Windows
- 环境方式：VMware Workstation Pro 虚拟机
- Ubuntu 版本：Ubuntu 22.04 LTS Desktop
- Agent 工具：Codex

 心得与遇到的问题

本次作业中，我先向 Codex 说明电脑环境和 VMware 方案，由 Agent 帮我规划虚拟机创建、Ubuntu 安装过程；虚拟磁盘、安装过程均由自己完成，练习 `rm -i` 时，我在命令已经结束、终端重新出现提示符后才输入 `y`，结果提示“未找到命令”。后来我理解到，`y` 必须在命令等待确认时输入，重新执行后删除成功。通过这次操作，我熟悉了 `pwd`、`ls`、`cd`、`cp`、`mv`、`rm`、`cat`、`head` 和 `tail` 等命令，也认识到 Agent 可以帮助分析和排错，但关键操作仍需自己核实。最后Agent还提供了把作业上传到正确位置的方法，我也学到了如何使用ubantu,如何使用GIthub,学会了利用Agent工具来解决遇到的问题。
