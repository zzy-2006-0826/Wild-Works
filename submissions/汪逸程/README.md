# 第二课作业

## 环境与工具
- **环境**：VirtualBox 虚拟机，Ubuntu 22.04
- **Agent 工具**：Deepseek


## 心得体会
作为一个纯小白，刚开始听说要装 Linux 系统时我一头雾水。在 Agent 的帮助下，我一步步下载并安装了虚拟机，成功部署了 Ubuntu 22.04。
搭建过程中遇到了不少问题：比如下载的镜像文件被 Windows 拦截；挂载光盘时不知道怎么操作；安装完重启时卡在了“移除安装介质”的界面。Agent 帮了我大忙，它不仅告诉我具体的点击步骤，还耐心解释了“清空磁盘”只影响虚拟硬盘，不会破坏真实电脑，打消了我的顾虑。
我从一开始对虚拟机充满恐惧，变成了能独立敲出 `pwd`、`mkdir` 等命令。我也学会了如何有效求助：遇到报错不要慌，把报错截图发给 Agent，它就能精准指导。这次作业极大提升了我解决计算机问题的信心。
