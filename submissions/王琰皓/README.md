## 四、遇到的问题与解决

1. **`less` 看完按 q 退出后，屏幕上的文件内容消失了**：原因是 `less` 退出时会恢复进入前的屏幕。改用 `less -X`（不初始化和还原终端）后，内容会留在屏幕上，方便对照和截图。
2. **`cp -i` 第一次复制没有出现覆盖提示**：`-i` 只在目标文件已经存在、可能被覆盖时才会询问。第二次对同名文件执行 `cp -i` 时才出现 `cp: overwrite 'README.backup.md'?`，输入 `y` 后完成覆盖。
3. **删除前确认目标路径**：`rm -i` 会逐条询问，输入 `y` 才真正删除；普通 `rm` 不会进回收站，所以删除前先用 `ls -la docs/` 看清目录内容，再删除自己创建的文件。
